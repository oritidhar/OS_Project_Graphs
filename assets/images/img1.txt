Practical Codex Setup for VS Code

1. Install VS Code

Install Visual Studio Code on the computer.

2. Install Codex Extension

Open VS Code.

Go to Extensions.

Search:

Codex

Install the official OpenAI Codex extension.

3. Sign In

Open the Codex panel inside VS Code.

Sign in with the ChatGPT/OpenAI account.

4. Open the Project Folder

Do not open only one file.

Open the full project folder:

File -> Open Folder

Example:

OS_Project_Graphs

5. If Using Linux / WSL

Open a terminal inside the project folder and run:

code .

This opens the current folder in VS Code.
